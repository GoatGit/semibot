# Semibot Trademark and Brand Policy

This file is a first draft.

## Ownership

The following are reserved brand assets of the Semibot project owner:

- the name `Semibot`
- the Semibot logo
- official domains, including `semibot.ai` and `releases.semibot.ai`
- official website copy, product branding, and brand presentation

## No Trademark License in Code License

The source code license does not grant permission to use the Semibot name,
logos, or other brand assets in a way that suggests affiliation, endorsement,
official status, or commercial authorization.

## Allowed Uses

Without separate written permission, you may:

- refer to Semibot factually to describe compatibility or origin;
- link to the official repository or website;
- state that your work is "based on Semibot" or "forked from Semibot" if that
  statement is accurate.

## Prohibited Uses

Without separate written permission, you may not:

- name a commercial product or hosted service `Semibot`;
- use Semibot logos or brand identity in a way that implies official status;
- operate a fork, hosted service, or derivative product under the Semibot name;
- register domain names, social handles, or package names likely to confuse
  users into believing they are official Semibot properties.

## Forks and Derivatives

Forks are allowed only under the source code license. However, forks must adopt
their own distinct name, logo, and branding unless explicitly authorized.

Recommended phrasing:

- "Forked from Semibot"
- "Based on Semibot Core"

Not allowed without permission:

- "Semibot Enterprise"
- "Semibot Cloud"
- "Official Semibot Partner Edition"

## Commercial Use

Any commercial use of the Semibot brand, including reseller, OEM, partner,
hosted service, or marketplace distribution, requires separate written
authorization.

## Contact

Commercial license and brand use requests should be handled through the project
owner's official commercial contact channel.

This document should be reviewed by qualified counsel before external release.
